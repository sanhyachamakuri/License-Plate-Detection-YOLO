# Dataset Information

This project uses a license plate image dataset for training and validating a YOLO object detection model.

## Dataset Summary

- Total images: 1,695
- Training images: 1,526
- Validation images: 169
- Number of classes: 1
- Class name: license_plate
- Annotation format: YOLO bounding-box format

The dataset contains vehicle images with labeled license plates. The annotations are used to train the model to locate license plates in images.

The full dataset is not uploaded to this repository because of its file size.
